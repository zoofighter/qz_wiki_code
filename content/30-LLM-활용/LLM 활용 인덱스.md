# LLM 활용 인덱스

LLM은 정답 복사 도구가 아니라 설명, 힌트, 반례, 테스트, 코드 리뷰를 얻는 학습 보조 도구로 사용한다.

## 기본 워크플로

1. 문제를 자신의 말로 요약한다.
2. 10분 이상 직접 풀이한다.
3. 막힌 지점을 구체적으로 기록한다.
4. 정답 대신 단계별 힌트를 요청한다.
5. 직접 코드를 완성한다.
6. 컴파일과 테스트를 수행한다.
7. LLM에게 오류 가능성과 개선점을 검토시킨다.
8. 최종 이해를 자신의 문장으로 노트에 정리한다.

## 추천 프롬프트 구조

```text
역할: 초보 대학생을 돕는 프로그래밍 튜터
언어와 버전: C17 또는 프로젝트의 Java LTS 버전
학습 주제: 한 가지 개념
현재 이해: 내가 이해한 내용
막힌 부분: 구체적인 질문
원하는 도움: 정답 대신 힌트 / 코드 리뷰 / 테스트 생성
출력 형식: 설명, 최소 예제, 예상 출력, 흔한 실수
제약: 검증되지 않은 API 금지, 초보자 수준 유지
```

## 검증 질문

- 이 코드가 실제로 컴파일되는가?
- 어떤 입력에서 실패하는가?
- 사용한 문법이 지정 버전에 존재하는가?
- 더 단순한 구현이 있는가?
- 설명과 코드가 서로 일치하는가?
- 내가 이 코드를 보지 않고 다시 작성할 수 있는가?

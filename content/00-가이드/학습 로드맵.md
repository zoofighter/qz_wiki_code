# 학습 로드맵

## 1단계: 공통 프로그래밍 기초

- 개발 환경과 터미널
- 소스 코드, 컴파일, 실행
- 변수, 자료형, 연산자
- 조건문과 반복문
- 함수와 문제 분해
- 배열과 문자열
- 디버깅 기초

먼저 [[C 기초 인덱스]]를 따라가며 컴퓨터가 프로그램을 실행하는 기본 원리를 익힌다.

## 2단계: C 기초

- [[C 시작하기]]
- 변수와 자료형
- 표준 입력과 출력
- 조건문과 반복문
- 함수와 스코프
- 배열과 문자열
- 포인터
- 구조체
- 동적 메모리
- 파일 입출력

## 3단계: Java 기초

- [[Java 시작하기]]
- 변수와 자료형
- 조건문과 반복문
- 메서드와 배열
- 클래스와 객체
- 캡슐화와 상속
- 인터페이스
- 예외 처리
- 컬렉션
- 파일 입출력

## 4단계: 비교 학습

C와 Java에서 같은 문제를 각각 구현해 다음 차이를 관찰한다.

| 주제 | C | Java |
|---|---|---|
| 실행 | 네이티브 실행 파일 | JVM에서 바이트코드 실행 |
| 메모리 | 직접 관리 비중이 큼 | 가비지 컬렉터가 관리 |
| 문자열 | 문자 배열 중심 | `String` 객체 중심 |
| 코드 구성 | 함수와 구조체 | 클래스와 객체 |

## 5단계: 프로젝트

작은 콘솔 프로젝트부터 시작한다.

- 숫자 맞히기 게임
- 성적 관리 프로그램
- 연락처 관리 프로그램
- 텍스트 기반 일정 관리 프로그램

프로젝트 기록 방식은 [[프로젝트 인덱스]]를 참고한다.

## 6단계: LLM과 복습

[[LLM 활용 인덱스]]의 절차에 따라 설명 요청, 힌트 요청, 테스트 생성, 코드 리뷰를 수행한다. LLM이 만든 답은 항상 실행하고 검증한다.
